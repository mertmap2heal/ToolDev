Shared CSS in _chrome.css — every page reuses topbar, sidebar, page-head, subbar, status bar, buttons, pills, tabs, table primitives, status pills, DAL chips, severity badges, and avatars. Module-specific styles are inlined in each page's <style> block so they're easy to tune one screen at a time without touching the rest.

Cross-links — sidebar navigation works between all 10 + 2 anchor pages. Tabs inside Dashboard, Project Landing, Verification and Safety let you A↔B switch in place. Anchor links land on ../requirements-page-v3.html and ../parameters-page-v2.html.

Not yet covered — drawer/modal interaction states, midnight theme, mobile breakpoints, the deep system-definition / PBS / interface-management module pages. Happy to keep going.
