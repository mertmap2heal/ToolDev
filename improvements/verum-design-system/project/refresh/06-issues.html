Description

During HIL run VER-0301-R7 on rig RIG-02, GPS reacquisition after a sustained 6 g banking manoeuvre took 1.84 s, exceeding the 1.20 s ceiling defined in REQ-1024.

Cause is suspected to be a stale almanac in the receiver state cache; on cold-start path the unit takes 1.6–2.1 s. Banking flushes the cache when bank angle > 45° for > 250 ms.
